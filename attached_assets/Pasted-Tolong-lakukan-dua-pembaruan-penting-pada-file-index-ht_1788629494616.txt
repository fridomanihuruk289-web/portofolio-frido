=== 1. EMBED TABLEAU INTERAKTIF UNTUK PROYEK 1 & 2 ===
Saya ingin menampilkan dashboard Tableau secara langsung (interaktif) untuk Proyek 1 dan Proyek 2. Ganti komentar <!-- MASUKKAN KODE EMBED TABLEAU DI SINI --> pada masing-masing proyek dengan kode di bawah ini.
PENTING: Saya sudah memodifikasi skrip JavaScript-nya agar 'vizElement.style.width' selalu '100%' dan tingginya otomatis menyesuaikan rasio layar (divElement.offsetWidth * 0.75) agar dashboard tidak terpotong atau berantakan di layar desktop maupun mobile. 
Pastikan tag pembungkus luar (container) iframe proyek ini tidak memiliki properti overflow yang memotong konten.

Kode untuk Proyek 1 (Industrial Market & Investor Opportunity Mapping):
```html
<div class='tableauPlaceholder' id='viz1788628665009' style='position: relative; width: 100%;'>
    <noscript><a href='#'><img alt='Dashboard 2 ' src='[https://public.tableau.com/static/images/Pr/ProjekKIM/Dashboard2/1_rss.png](https://public.tableau.com/static/images/Pr/ProjekKIM/Dashboard2/1_rss.png)' style='border: none' /></a></noscript>
    <object class='tableauViz' style='display:none;'>
        <param name='host_url' value='https%3A%2F%2Fpublic.tableau.com%2F' /> 
        <param name='embed_code_version' value='3' /> 
        <param name='site_root' value='' />
        <param name='name' value='ProjekKIM/Dashboard2' />
        <param name='tabs' value='no' />
        <param name='toolbar' value='yes' />
        <param name='static_image' value='[https://public.tableau.com/static/images/Pr/ProjekKIM/Dashboard2/1.png](https://public.tableau.com/static/images/Pr/ProjekKIM/Dashboard2/1.png)' /> 
        <param name='animate_transition' value='yes' />
        <param name='display_static_image' value='yes' />
        <param name='display_spinner' value='yes' />
        <param name='display_overlay' value='yes' />
        <param name='display_count' value='yes' />
        <param name='language' value='en-US' />
    </object>
</div>
<script type='text/javascript'>
    var divElement = document.getElementById('viz1788628665009');
    var vizElement = divElement.getElementsByTagName('object')[0];
    if ( divElement.offsetWidth > 800 ) { 
        vizElement.style.width='100%'; 
        vizElement.style.height=(divElement.offsetWidth*0.75)+'px';
    } else if ( divElement.offsetWidth > 500 ) { 
        vizElement.style.width='100%'; 
        vizElement.style.height=(divElement.offsetWidth*0.75)+'px';
    } else { 
        vizElement.style.width='100%'; 
        vizElement.style.height='1477px';
    }
    var scriptElement = document.createElement('script');
    scriptElement.src = '[https://public.tableau.com/javascripts/api/viz_v1.js](https://public.tableau.com/javascripts/api/viz_v1.js)';
    vizElement.parentNode.insertBefore(scriptElement, vizElement);
</script>
